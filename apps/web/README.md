# KaziBoost Web App

Next.js frontend scaffold for the KaziBoost product shell.

## API configuration

The dashboard reads the public readiness endpoint from `KAZIBOOST_API_URL` (server-only) or `NEXT_PUBLIC_API_URL`. Set one when the API is not available at the local development default.

## Included
- Marketing home page
- Dashboard shell
- Dashboard onboarding progress and feedback capture
- Operational settings and tenant controls
- Website publish flow UI
- CRM lead inbox and detail view
- WhatsApp conversation workspace
- Training knowledge base shell
- Payment reconciliation and checkout UI
- SEO calendar and content workflow UI
- Shared global styling
- App Router structure
